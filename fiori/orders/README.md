# Purchase Orders App

Implemented Fiori elements List Report/Object Page consuming the ABAP RAP OData V4 service.

The application supports the purchase-order header/item composition, draft editing, annotations, validations and lifecycle actions exposed by the ABAP behavior. It was validated through the RAP service-binding preview in the SAP BTP ABAP Environment.

The UI source is generated from ABAP metadata and is not exported in this repository. Phase 14 still needs curated screenshots of the list, Object Page, item composition and approve/cancel flow.
